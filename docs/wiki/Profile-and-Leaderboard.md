# Profile and Leaderboard

**English** · [Deutsch](Profil-und-Bestenliste)

## Profile

Every finished game against the AI or online earns experience – more for victories and higher difficulty. As you level up, your title rises: Häuptling (Chief), Fürst (Prince), König (King), Kaiser (Emperor), Legende (Legend). The profile is stored in the browser; in the menu under **Profil** (Profile) you find achievements, cosmetics and statistics.

## Matching AI difficulty

If you win three free games in a row against the AI on the same level, the result screen offers a game on the next level straight away. After a defeat there is “Nochmal – etwas leichter” (Again – a bit easier).

## Achievements and cosmetics

20 achievements are waiting, for example “Blitzkrieg” (conquer everything in at most 25 turns) or “Stammgast” (Regular – play the daily challenge three days in a row). Levels and achievements unlock cosmetics: banners, helmet plumes and city decorations for your own cities and units.

## Name and leaderboard

With a name (3–16 characters), your daily and weekly challenge results appear on the leaderboard of all players. Only your best result counts. You can change your name once a day; during the first 15 minutes after choosing your first name as often as you like, in case you made a typo. Names of profiles that never played (level 1, no points, nothing saved for half a year) become available again.

So that nobody can make up scores, the game sends the list of your moves along with the result. A checking program replays the game with it and enters the recomputed score. Until then the leaderboard shows “Dein Ergebnis wird geprüft” (Your result is being checked), which usually takes a few minutes. Only challenges played to the very end count, and a game continued from an older save has no move log and does not count.

## Profile code

The profile code takes your name, level, achievements and your online matches to another device: open **Profil-Code** (Profile code) in the menu and enter it on the other device. Anyone who knows the code plays as you – do not share it.

- **Als Datei speichern** (Save as file) downloads the code as a text file. Do this once: if the browser clears its data and the code is not written down anywhere, your profile and online matches are gone.
- **Neuen Code erzeugen** (Create new code) if someone has seen your code. The old code then stops working everywhere, including in running online matches. Enter the new code on your other devices.

## What is stored

The server only stores your name, your profile data and your scores. Your secret player ID is stored there only as a checksum (SHA-256).
