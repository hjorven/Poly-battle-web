# Profil und Bestenliste

## Profil

Jede beendete Partie gegen die KI oder online bringt Erfahrung – mehr bei Siegen und höherer Schwierigkeit. Mit den Stufen steigt dein Titel: Häuptling, Fürst, König, Kaiser, Legende. Das Profil liegt im Browser; im Menü unter **Profil** findest du Erfolge, Aussehen und Statistik.

## Passende KI-Stärke

Gewinnst du drei freie Partien gegen die KI in Folge auf derselben Stufe, bietet das Ergebnis direkt ein Spiel auf der nächsten Stufe an. Nach einer Niederlage gibt es „Nochmal – etwas leichter“.

## Erfolge und Aussehen

20 Erfolge warten, zum Beispiel „Blitzkrieg“ (alles in höchstens 25 Runden erobern) oder „Stammgast“ (drei Tage in Folge die Tagesherausforderung). Stufen und Erfolge schalten Aussehen frei: Banner, Helmbusch und Stadtschmuck für deine eigenen Städte und Einheiten.

## Name und Bestenliste

Mit einem Namen (3–16 Zeichen) erscheinen deine Ergebnisse der Tages- und Wochen-Herausforderung in der Bestenliste aller Spieler. Es zählt jeweils dein bester Wert.

## Profil-Code

Der Profil-Code nimmt Name, Stufe, Erfolge und deine Online-Partien auf ein anderes Gerät mit: Im Menü **Profil-Code** öffnen, auf dem anderen Gerät eingeben. Wer den Code kennt, spielt als du – gib ihn nicht weiter.

- **Als Datei speichern** lädt den Code als Textdatei herunter. Mach das einmal: Löscht der Browser seine Daten und der Code ist nirgends notiert, sind Profil und Online-Partien weg.
- **Neuen Code erzeugen**, wenn jemand den Code gesehen hat. Der alte Code gilt danach nirgends mehr, auch nicht in laufenden Online-Partien. Auf deinen anderen Geräten gibst du den neuen Code ein.

## Was gespeichert wird

Auf dem Server liegen nur dein Name, deine Profildaten und deine Punkte. Deine geheime Spieler-Kennung wird dort ausschließlich als Prüfsumme (SHA-256) gespeichert.
